Private categories & PIN

Kadu has two levels of protection. A private category hides entries from the main timeline, and a PIN locks the app itself and private categories.

Private category

Entries from a private category never appear in the main timeline, filters or general slideshows. The only way to see them is to open the category itself from the home screen.

How to make a category private

  1. On the home screen, press and hold a category card. For a new category, tap Add category.
  2. Turn on the Private switch (labeled “Hidden in the general timeline”).
  3. Tap Save (for a new category — Create).

On first launch Kadu already creates a “Private” category.

Without a PIN, privacy is only visual

Until a PIN is set, a private category is simply hidden from the timeline. Anyone holding your phone can open it from the home screen. To truly lock it, set a PIN.

PIN

How to set it

  1. Open Settings → PIN code.
  2. Tap Set PIN code.
  3. Enter 4 digits and repeat them to confirm.

When Kadu asks for the PIN

  • every time the app starts;
  • when opening a private category from the home screen;
  • before exporting data, since the backup contains private entries too.

How to change or turn it off

Open Settings → PIN code → Reset PIN code and enter the current code. After that the app stops asking for it. To set a new code, tap Set PIN code again.

Fake PIN

If someone might ask you to unlock your journal, set a second, fake code. It opens the app but hides all private categories. More in Fake PIN.

FAQ

I forgot my PIN

The PIN is stored only on your device and in encrypted form, so it can't be recovered or looked up — not even by us. Try to remember it. If that doesn't work, write to us.

To avoid this, choose a code you won't forget and make backups regularly.

Can I open Kadu with Face ID?

Not yet — Kadu is protected by a PIN only.
