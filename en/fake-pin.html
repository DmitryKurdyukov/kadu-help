Fake PIN Premium

A fake PIN is a second code for Kadu. It opens the app as usual, just without private categories. To anyone watching, it looks as if they never existed.

Why you'd need it

Sometimes you're asked to show your journal and it's awkward to refuse. Enter the fake code: the other person sees ordinary entries while your personal ones stay hidden. There's no “mode” or hint on screen.

What happens after entering the fake code

  • private categories disappear from the home screen;
  • their entries don't show in the timeline, filters, slideshow, book or export;
  • everything else works as usual.

No data is deleted. When you enter your real PIN, everything is back in place.

How to set it

  1. First set your main PIN: Settings → PIN code → Set PIN code. Without it the app doesn't ask for a code at launch, so a fake one is useless.
  2. Tap Set fake PIN code.
  3. Enter 4 digits and repeat them.
The codes must be different

If the fake code matches the main one, Kadu will always open in normal mode and the fake code won't work.

How to turn it off

Open Settings → PIN code → Reset fake PIN code and enter your main PIN. The fake code can't reset itself — otherwise anyone who knows it could turn off the protection.

FAQ

How do I get back to the full journal after using the fake code?

Close the app completely, open it again and enter your main PIN.
