Export & import

Export creates a backup of your journal in a single zip file. Import brings it back or moves entries over from Day One and Apple Journal. It all lives in Settings → Import / Export.

Export: backup

  1. Open Settings → Import / Export → Export.
  2. Tap Export all data. If a PIN is set, Kadu asks for it first.
  3. Wait until it finishes. With lots of photos and videos this can take a few minutes.
  4. In the sheet that opens, choose where to save the file: Save to Files (for example, iCloud Drive), send it to a computer or to cloud storage.

The file is named something like kadu-export-10-19-2026.zip. It contains all entries, categories, tags, photos, videos and voice notes.

Export one category Premium

On the same screen, the Export by category block lets you export entries from one category only — for example, to share a travel journal.

Import a Kadu backup

  1. Open Settings → Import / Export.
  2. Tap Import and choose the zip file created by Kadu export.
  3. Wait for the “Import successful” message.
Import doesn't erase anything

Entries from the backup are added to what's already in the app. Entries that already exist in Kadu aren't added twice, so you can safely import the same file again.

Moving to a new phone

  1. On the old phone, make an export and save the file somewhere the new phone can reach: iCloud Drive, Google Drive or Files.
  2. Install Kadu on the new phone.
  3. Import that file.

The PIN isn't part of the backup. Set it again on the new phone.

Import from Day One

  1. In Day One, export your journal in JSON format. You'll get a zip archive.
  2. In Kadu, open Settings → Import / Export and tap Import from Day One (zip).
  3. Choose the archive.

How data is moved:

  • the main Day One journal (“Journal”) goes to the default category;
  • each other journal gets a category with the same name. If one already exists, entries are added to it;
  • photos and hashtags move along with the entries.

Import from Apple Journal

  1. Export your entries from the Journal app. You'll get a folder containing an index.html file and Entries and Resources folders.
  2. Compress that folder into a zip. In the Files app, press and hold the folder and choose Compress.
  3. In Kadu, tap Import from Apple Journal (zip) and choose the archive.

If an entry's date can't be recognized, it gets today's date. Kadu tells you how many such entries there are. You can fix the date manually in the editor.

FAQ

Import says the file looks like an export from another app

You chose a Day One or Apple Journal archive in the regular Import item. Those archives have their own buttons: Import from Day One (zip) and Import from Apple Journal (zip). Kadu will tell you which one to use.

“No data.json found in the archive.”

The file isn't a Kadu backup or was modified after export. Make sure you choose the original zip created with Export all data.

Export takes a very long time

Kadu copies all photos and videos into the archive, and for a large journal that takes a few minutes. Keep the app open until it finishes.
