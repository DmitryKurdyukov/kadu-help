書き出しと読み込み

書き出しは日記のバックアップを 1 つの zip ファイルにします。読み込みはそれを復元したり、Day One や Apple Journal の記録を取り込んだりします。すべて 設定 → インポート / エクスポート にあります。

書き出し：バックアップ

  1. 設定 → インポート / エクスポート → エクスポート を開きます。
  2. 全データをエクスポート をタップします。PIN を設定している場合は、先に入力を求められます。
  3. 完了まで待ちます。写真やビデオが多いと数分かかることがあります。
  4. 表示された画面で保存先を選びます："ファイル"に保存（例：iCloud Drive）、パソコンやクラウドストレージに送るなど。

ファイル名は kadu-export-10-19-2026.zip のようになります。すべての記録、カテゴリ、タグ、写真、ビデオ、ボイスメモが含まれます。

1 つのカテゴリを書き出す Premium

同じ画面の カテゴリ別にエクスポート ブロックで、1 つのカテゴリの記録だけを書き出せます。旅日記を共有したいときなどに便利です。

Kadu のバックアップを読み込む

  1. 設定 → インポート / エクスポート を開きます。
  2. インポート をタップし、Kadu の書き出しで作った zip を選びます。
  3. 「インポート完了」というメッセージが出るまで待ちます。
読み込みで何かが消えることはありません

バックアップの記録は、すでにアプリにある記録に追加されます。Kadu にすでにある記録は重複しないため、同じファイルを何度読み込んでも安心です。

新しい端末への移行

  1. 古い端末で書き出しを行い、新しい端末からアクセスできる場所（iCloud Drive、Google ドライブ、ファイル）に保存します。
  2. 新しい端末に Kadu をインストールします。
  3. そのファイルを読み込みます。

PIN はバックアップに含まれません。新しい端末で設定し直してください。

Day One からの読み込み

  1. Day One でジャーナルを JSON 形式で書き出します。zip アーカイブができます。
  2. Kadu で 設定 → インポート / エクスポート を開き、Day Oneからインポート（zip） をタップします。
  3. アーカイブを選びます。

データの移り方：

  • Day One のメインジャーナル（「Journal」）はデフォルトのカテゴリに入ります。
  • ほかのジャーナルには同じ名前のカテゴリが作られます。すでにあれば、そこに記録が追加されます。
  • 写真とハッシュタグも記録と一緒に移ります。

Apple Journal からの読み込み

  1. 「ジャーナル」アプリから記録を書き出します。index.html ファイルと Entries・Resources フォルダが入ったフォルダができます。
  2. そのフォルダを zip に圧縮します。「ファイル」アプリでフォルダを長押しし、圧縮 を選びます。
  3. Kadu で Apple Journalからインポート（zip） をタップし、アーカイブを選びます。

日付を認識できなかった記録には今日の日付が付きます。Kadu がその件数を知らせます。日付はエディタで手動で直せます。

よくある質問

読み込み時に「別のアプリの書き出しのようです」と表示される

Day One や Apple Journal のアーカイブを通常の インポート で選んでいます。これらには専用のボタンがあります：Day Oneからインポート（zip） と Apple Journalからインポート（zip）。どれを使えばよいかは Kadu が案内します。

「アーカイブにdata.jsonが見つかりません。」

ファイルが Kadu のバックアップではないか、書き出し後に変更されています。全データをエクスポート で作った元の zip を選んでください。

書き出しにとても時間がかかる

Kadu はすべての写真とビデオをアーカイブにコピーするため、日記が大きいと数分かかります。終わるまでアプリを開いたままにしてください。
