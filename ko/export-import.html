내보내기와 가져오기

내보내기는 일기 백업을 zip 파일 하나로 만듭니다. 가져오기는 백업을 복원하거나 Day One과 Apple Journal의 기록을 옮겨 옵니다. 모두 설정 → 가져오기 / 내보내기에 있습니다.

내보내기: 백업

  1. 설정 → 가져오기 / 내보내기 → 내보내기를 엽니다.
  2. 모든 데이터 내보내기를 탭합니다. PIN이 설정되어 있으면 먼저 입력을 요청합니다.
  3. 끝날 때까지 기다립니다. 사진과 동영상이 많으면 몇 분 걸릴 수 있습니다.
  4. 열린 창에서 저장할 위치를 고릅니다: 파일에 저장(예: iCloud Drive), 컴퓨터나 클라우드 저장소로 보내기 등.

파일 이름은 kadu-export-10-19-2026.zip과 비슷합니다. 모든 기록, 카테고리, 태그, 사진, 동영상, 음성 메모가 들어 있습니다.

카테고리 하나만 내보내기 Premium

같은 화면의 카테고리별 내보내기 블록에서 카테고리 하나의 기록만 내보낼 수 있습니다. 여행 일기를 공유할 때 유용합니다.

Kadu 백업 가져오기

  1. 설정 → 가져오기 / 내보내기을 엽니다.
  2. 가져오기를 탭하고 Kadu 내보내기로 만든 zip을 고릅니다.
  3. “가져오기 완료” 메시지가 나올 때까지 기다립니다.
가져오기는 아무것도 지우지 않습니다

백업의 기록은 앱에 이미 있는 기록에 추가됩니다. Kadu에 이미 있는 기록은 중복되지 않으므로 같은 파일을 다시 가져와도 안전합니다.

새 휴대폰으로 옮기기

  1. 이전 휴대폰에서 내보내기를 하고, 새 휴대폰에서 접근할 수 있는 곳(iCloud Drive, Google Drive, 파일)에 저장합니다.
  2. 새 휴대폰에 Kadu를 설치합니다.
  3. 그 파일을 가져옵니다.

PIN은 백업에 포함되지 않습니다. 새 휴대폰에서 다시 설정하세요.

Day One에서 가져오기

  1. Day One에서 저널을 JSON 형식으로 내보냅니다. zip 파일이 만들어집니다.
  2. Kadu에서 설정 → 가져오기 / 내보내기을 열고 Day One에서 가져오기 (zip)를 탭합니다.
  3. 파일을 고릅니다.

데이터가 옮겨지는 방식:

  • Day One의 기본 저널(“Journal”)은 기본 카테고리로 들어갑니다.
  • 나머지 저널마다 같은 이름의 카테고리가 만들어집니다. 이미 있으면 그 카테고리에 기록이 추가됩니다.
  • 사진과 해시태그도 기록과 함께 옮겨집니다.

Apple Journal에서 가져오기

  1. 저널 앱에서 기록을 내보냅니다. index.html 파일과 Entries, Resources 폴더가 든 폴더가 만들어집니다.
  2. 그 폴더를 zip으로 압축합니다. 파일 앱에서 폴더를 길게 누르고 압축을 선택합니다.
  3. Kadu에서 Apple Journal에서 가져오기 (zip)를 탭하고 파일을 고릅니다.

날짜를 인식하지 못한 기록에는 오늘 날짜가 붙습니다. Kadu가 그 개수를 알려 줍니다. 날짜는 편집기에서 직접 고칠 수 있습니다.

자주 묻는 질문

가져오기에서 다른 앱의 내보내기 파일 같다고 나와요

Day One이나 Apple Journal 파일을 일반 가져오기 항목에서 골랐습니다. 이런 파일에는 전용 버튼이 있습니다: Day One에서 가져오기 (zip)와 Apple Journal에서 가져오기 (zip). 어떤 것을 써야 할지 Kadu가 알려 줍니다.

“아카이브에서 data.json을 찾을 수 없습니다.”

파일이 Kadu 백업이 아니거나 내보낸 뒤 변경되었습니다. 모든 데이터 내보내기로 만든 원본 zip을 고르세요.

내보내기가 너무 오래 걸려요

Kadu는 모든 사진과 동영상을 파일에 복사하므로 일기가 크면 몇 분 걸립니다. 끝날 때까지 앱을 열어 두세요.
