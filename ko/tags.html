태그

태그는 여행, 사람, 프로젝트처럼 공통 주제로 기록을 묶어 줍니다. Kadu에는 태그 전용 입력란이 없고, 태그는 기록 본문에 바로 씁니다.

태그 추가 방법

  1. 본문에 #를 입력하고 띄어쓰기 없이 바로 단어를 씁니다: #여행
  2. 단어 뒤에 공백을 입력합니다. 그래야 진짜 태그가 됩니다.
  3. 태그 #여행이 강조 색상으로 표시되었는지 확인합니다.
  4. 기록을 저장합니다.
드디어 바다에 도착 #여행 #바다2025 커피 한 잔
가장 중요한 규칙: 태그에 색이 들어와야 합니다

#가 붙은 단어가 색이 바뀌지 않고 일반 글자로 남아 있다면 태그가 아닙니다. 필터에 나타나지 않고 그 태그로 기록을 찾을 수도 없습니다. 대부분 태그 뒤에 공백이 없을 때 생깁니다. 예를 들어 본문의 마지막 단어인 경우입니다.

한 기록에 태그를 원하는 만큼 넣을 수 있고, 본문의 처음·중간·끝 어디에 두어도 됩니다. 각 태그 뒤에 공백만 넣으세요.

태그에 색이 들어오지 않을 때

단어 바로 뒤에 커서를 두고 스페이스를 누르세요. 그래도 안 되면 태그를 지우고 #, 단어, 공백 순서로 다시 입력합니다.

작성 규칙

예시결과이유
#Travel과 #travel태그 하나 travel대소문자를 구분하지 않습니다
#첫 눈첫만공백에서 태그가 끝납니다
#約會, #ความทรงจำ사용 가능모든 언어의 문자를 쓸 수 있습니다
팁

여러 단어로 된 태그는 밑줄이나 하이픈으로 이어 주세요: #첫_눈, #생일-파티

태그로 기록 찾기

  1. 타임라인 탭을 엽니다.
  2. 화면 위쪽의 필터를 탭합니다.
  3. 태그 블록에서 원하는 태그를 선택합니다. 태그가 많으면 태그 검색… 칸에 이름을 입력하세요.
  4. 필터를 적용합니다.

많이 쓴 태그일수록 위에 표시됩니다.

여러 태그를 선택한 경우

선택한 태그 중 하나라도 있는 기록이 표시됩니다. 예를 들어 #바다와 #산을 고르면 바다 여행과 산 여행이 모두 보입니다.

선택을 모두 해제하려면 블록 제목 옆의 지우기를 탭하세요.

태그 필터는 슬라이드쇼와 책에도 적용됩니다. 예를 들어 #여행을 선택하면 그 여행만 담은 영상을 볼 수 있습니다. 자세한 내용은 필터와 검색을 참고하세요.

태그 수정 또는 삭제

기록을 열고 #가 붙은 단어를 고치거나 지운 뒤 저장합니다. 태그 목록은 자동으로 갱신됩니다. 어떤 기록에서도 쓰이지 않는 태그는 필터에서 사라집니다.

자주 묻는 질문

필터에 아직 태그가 없다고 나와요

태그는 저장된 기록에서 한 번 이상 써야 나타납니다. 태그에 색이 들어왔는지 확인하세요. #가 붙은 일반 글자는 태그로 인식되지 않습니다.

Day One이나 Apple Journal의 태그도 유지되나요?

네. 가져오기 중에 Kadu가 가져온 기록 본문에서 해시태그를 찾아 목록에 추가합니다.

기록은 있는데 태그로 찾을 수 없어요

세 가지를 확인하세요:

  • 기록 속 태그가 강조 색상으로 표시되어 있는지. 아니라면 뒤에 공백을 넣고 기록을 다시 저장하세요.
  • 필터는 # 뒤의 단어를 그대로 찾습니다. 중간에 공백이 있으면 태그가 끝납니다.
  • 기록이 비공개 카테고리에 있지 않은지. 전체 타임라인에는 표시되지 않습니다.
