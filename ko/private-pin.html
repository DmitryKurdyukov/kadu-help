비공개 카테고리와 PIN

Kadu에는 두 단계의 보호 장치가 있습니다. 비공개 카테고리는 기록을 전체 타임라인에서 숨기고, PIN은 앱 자체와 비공개 카테고리를 잠급니다.

비공개 카테고리

비공개 카테고리의 기록은 전체 타임라인, 필터, 전체 슬라이드쇼에 절대 나타나지 않습니다. 볼 수 있는 유일한 방법은 홈 화면에서 그 카테고리를 직접 여는 것입니다.

카테고리를 비공개로 만들기

  1. 홈 화면에서 카테고리 카드를 길게 누릅니다. 새 카테고리라면 카테고리 추가를 탭합니다.
  2. 비공개 스위치를 켭니다(설명: “일반 타임라인에서 숨김”).
  3. 저장를 탭합니다(새 카테고리는 만들기).

처음 실행할 때 Kadu가 이미 “비공개” 카테고리를 만들어 둡니다.

PIN이 없으면 보이지 않게만 할 뿐입니다

PIN을 설정하기 전까지 비공개 카테고리는 타임라인에서 숨겨질 뿐입니다. 휴대폰을 손에 쥔 사람이라면 누구나 홈 화면에서 열 수 있습니다. 제대로 잠그려면 PIN을 설정하세요.

PIN

설정 방법

  1. 설정 → PIN 코드를 엽니다.
  2. PIN 코드 설정를 탭합니다.
  3. 숫자 4자리를 입력하고 확인을 위해 한 번 더 입력합니다.

Kadu가 PIN을 묻는 경우

  • 앱을 실행할 때마다
  • 홈 화면에서 비공개 카테고리를 열 때
  • 데이터 내보내기 전 — 백업에 비공개 기록도 포함되기 때문입니다

변경하거나 끄는 방법

설정 → PIN 코드 → PIN 코드 초기화를 열고 현재 코드를 입력합니다. 그 후로 앱은 코드를 묻지 않습니다. 새 코드를 설정하려면 다시 PIN 코드 설정를 탭하세요.

가짜 PIN

누군가 일기 잠금을 풀어 달라고 할 수 있다면 두 번째 가짜 코드를 설정하세요. 앱은 열리지만 비공개 카테고리는 모두 숨겨집니다. 자세한 내용은 가짜 PIN을 참고하세요.

자주 묻는 질문

PIN을 잊어버렸어요

PIN은 기기에만 암호화되어 저장되므로 저희를 포함해 누구도 복구하거나 확인할 수 없습니다. 기억을 떠올려 보세요. 그래도 안 되면 문의해 주세요.

이런 일을 막으려면 잊지 않을 코드를 고르고 정기적으로 백업하세요.

Face ID로 Kadu를 열 수 있나요?

아직은 아닙니다. Kadu는 PIN으로만 보호됩니다.
