데이터 저장 위치

계정도 클라우드도 없습니다. 모든 기록, 사진, 동영상, 음성 메모는 기기의 Kadu 안에만 저장됩니다.

이것이 의미하는 것

  • 나 말고는 아무도 기록을 볼 수 없습니다. 저희는 글이나 사진을 받지 않으며, 어떤 서버에도 저장되지 않습니다.
  • 가입이 필요 없습니다. 앱은 바로, 오프라인에서도 작동합니다.
  • 기기 간 동기화가 없습니다. 일기는 휴대폰 한 대에 있습니다. 옮기려면 내보내기와 가져오기를 사용하세요.

사진은 Kadu로 복사됩니다

기록에 사진이나 동영상을 첨부하면 Kadu는 파일의 자체 사본을 저장합니다. 그래서:

  • 갤러리에서 사진을 지워도 Kadu에는 남습니다.
  • Kadu의 사진과 동영상은 갤러리와 별도로 휴대폰 저장 공간을 차지합니다.

반대 방향의 옵션도 있습니다: 설정 → 기타 → 사진과 동영상을 갤러리에 저장. 켜 두면 Kadu 안에서 카메라로 찍은 사진과 동영상이 휴대폰 갤러리에도 저장됩니다.

일기를 잃지 않으려면

앱을 삭제하면 모든 기록이 삭제됩니다

데이터는 Kadu 안에만 있으므로 앱을 삭제하거나 휴대폰을 초기화하거나 잃어버리면 사라집니다. 저희는 데이터를 갖고 있지 않아 복구해 드릴 수 없습니다.

확실한 대비책은 백업뿐입니다. 정기적으로 내보내기를 하고 파일을 휴대폰 밖에 보관하세요: iCloud Drive, Google Drive, 컴퓨터, 이메일 등.

팁

한 달에 한 번, 그리고 휴대폰 교체·초기화·Kadu 재설치 전에는 반드시 백업하세요.

모든 데이터 삭제

설정 → 가져오기 / 내보내기 → 모든 데이터 삭제는 모든 기록, 카테고리, 미디어를 영구적으로 지웁니다. 데이터가 필요할 수 있다면 먼저 내보내세요.
