가짜 PIN Premium

가짜 PIN은 Kadu의 두 번째 코드입니다. 평소처럼 앱을 열지만 비공개 카테고리는 보이지 않습니다. 보는 사람에게는 처음부터 없었던 것처럼 보입니다.

어디에 쓰나요?

일기를 보여 달라는 부탁을 거절하기 곤란할 때가 있습니다. 그럴 때 가짜 코드를 입력하세요. 상대방은 평범한 기록만 보고, 개인적인 기록은 숨겨진 채로 남습니다. 화면에는 어떤 ‘모드’나 힌트도 나타나지 않습니다.

가짜 코드를 입력하면

  • 비공개 카테고리가 홈 화면에서 사라집니다.
  • 그 기록은 타임라인, 필터, 슬라이드쇼, 책, 내보내기 어디에도 나타나지 않습니다.
  • 나머지는 모두 평소대로 작동합니다.

데이터는 삭제되지 않습니다. 진짜 PIN을 입력하면 모든 것이 그대로 돌아옵니다.

설정 방법

  1. 먼저 기본 PIN을 설정합니다: 설정 → PIN 코드 → PIN 코드 설정. 기본 PIN이 없으면 앱이 실행할 때 코드를 묻지 않으므로 가짜 PIN이 소용없습니다.
  2. 가짜 PIN 설정를 탭합니다.
  3. 숫자 4자리를 입력하고 한 번 더 입력합니다.
두 코드는 달라야 합니다

가짜 코드가 기본 코드와 같으면 Kadu는 항상 일반 모드로 열리고 가짜 코드는 작동하지 않습니다.

끄는 방법

설정 → PIN 코드 → 가짜 PIN 초기화를 열고 기본 PIN을 입력합니다. 가짜 코드로는 스스로를 해제할 수 없습니다. 그렇지 않으면 가짜 코드를 아는 사람이 보호를 꺼 버릴 수 있기 때문입니다.

자주 묻는 질문

가짜 코드 사용 후 전체 일기로 돌아가려면?

앱을 완전히 종료한 뒤 다시 열고 기본 PIN을 입력하세요.
