# Kadu — руководство пользователя

Статический сайт с руководством для приложения Kadu на 22 языках. Сборка не нужна: файлы в репозитории и есть сайт.

## Структура

```
index.html            маршрутизатор: выбирает язык и перенаправляет в его папку
404.html              ловит старые и ошибочные ссылки и перенаправляет в нужный язык
<lang>/*.html         страницы на каждом языке (en, ru, de, zh-Hant, …)
assets/i18n.js        языки, подписи интерфейса и меню для каждого языка
assets/app.js         маршрутизация по языку, шапка, меню, переключатели языка и темы
assets/style.css      стили (цвета из темы приложения)
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

Коды языков совпадают с кодами в приложении (`SUPPORTED_LANGUAGES`).

## Ссылка из приложения

Кнопка «Обратная связь» должна открывать:

```
https://dmitrykurdyukov.github.io/kadu-help/?lang=<код языка>
```

Например, `?lang=de` открывает `/de/`. Если нужно открыть конкретную страницу: `?lang=de&page=tags`.

Как выбирается язык:

1. Параметр `?lang=`. Он понимает и системные коды: `pt-BR` → `pt`, `zh-Hant-TW` / `zh-TW` → `zh-Hant`, `zh-Hans-CN` → `zh`.
2. Язык, который человек выбрал на сайте раньше. Он сохраняется в браузере.
3. Язык браузера.
4. Если ни один не подошёл, английский.

`?lang=` работает на любой странице: `/en/tags.html?lang=fr` откроет `/fr/tags.html`.

## Как править тексты

Каждая страница — это обычный HTML в папке языка. Названия кнопок приложения выделены `<kbd>`. Они должны совпадать с переводами в `kadu/src/presentation/assets/translates/<lang>.json`.

## Как добавить раздел

1. Создайте `<slug>.html` в каждой папке языка. Проще всего скопировать существующую страницу и заменить `<title>`, `description` и `<article>`.
2. В `assets/i18n.js` добавьте `{ "href": "<slug>.html", "text": "…" }` в нужную группу `groups` каждого языка.

## Просмотр локально

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/?lang=ru.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`.
