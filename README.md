# Kadu — руководство пользователя

Статический сайт с руководством для приложения Kadu. Сборка не нужна: файлы в репозитории и есть сайт.

## Структура

```
index.html            главная
*.html                страницы разделов
assets/style.css      стили (цвета из темы приложения)
assets/app.js         общее меню, шапка, переключатель темы, «Назад / Далее»
assets/icon.png       иконка приложения
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

## Как добавить раздел

1. Скопируйте любую страницу раздела, например `tags.html`, и замените `<title>`, `description` и содержимое `<article>`.
2. Добавьте строку в массив `NAV` в `assets/app.js`. Меню и ссылки «Назад / Далее» обновятся на всех страницах.

## Просмотр локально

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`.
