Faux PIN Premium

Le faux PIN est un second code pour Kadu. Il ouvre l'app comme d'habitude, mais sans les catégories privées. Pour qui regarde, c'est comme si elles n'avaient jamais existé.

À quoi il sert

Il arrive qu'on vous demande de montrer votre journal et qu'il soit gênant de refuser. Saisissez le faux code : l'autre personne voit des entrées ordinaires, et vos entrées personnelles restent cachées. Aucun « mode » ni indice n'apparaît à l'écran.

Ce qui se passe après le faux code

  • les catégories privées disparaissent de l'écran d'accueil ;
  • leurs entrées n'apparaissent ni dans la frise, ni dans les filtres, le diaporama, le livre ou l'export ;
  • tout le reste fonctionne normalement.

Aucune donnée n'est supprimée. Quand vous saisissez votre vrai PIN, tout revient.

Le définir

  1. Définissez d'abord votre PIN principal : Réglages → Code PIN → Définir le code PIN. Sans lui, l'app ne demande aucun code à l'ouverture et un faux PIN ne sert à rien.
  2. Touchez Définir un faux code PIN.
  3. Saisissez 4 chiffres et répétez-les.
Les codes doivent être différents

Si le faux code est identique au principal, Kadu s'ouvrira toujours en mode normal et le faux code ne fonctionnera pas.

Le désactiver

Ouvrez Réglages → Code PIN → Réinitialiser le faux code PIN et saisissez votre PIN principal. Le faux code ne peut pas se désactiver lui-même : sinon, quiconque le connaît pourrait couper la protection.

Questions fréquentes

Comment retrouver le journal complet après le faux code ?

Fermez complètement l'app, rouvrez-la et saisissez votre PIN principal.
