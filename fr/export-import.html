Export et import

L'export crée une sauvegarde de votre journal dans un seul fichier zip. L'import la restaure ou reprend des entrées de Day One et Apple Journal. Tout se trouve dans Réglages → Importer / Exporter.

Export : sauvegarde

  1. Ouvrez Réglages → Importer / Exporter → Exporter.
  2. Touchez Exporter toutes les données. Si un PIN est défini, Kadu le demande d'abord.
  3. Attendez la fin. Avec beaucoup de photos et de vidéos, cela peut prendre quelques minutes.
  4. Dans la fenêtre qui s'ouvre, choisissez où enregistrer le fichier : Enregistrer dans Fichiers (par exemple iCloud Drive), l'envoyer sur un ordinateur ou dans un stockage cloud.

Le fichier s'appelle à peu près kadu-export-10-19-2026.zip. Il contient toutes les entrées, catégories, étiquettes, photos, vidéos et notes vocales.

Exporter une catégorie Premium

Sur le même écran, le bloc Exporter par catégorie permet d'exporter les entrées d'une seule catégorie, par exemple pour partager un carnet de voyage.

Importer une sauvegarde Kadu

  1. Ouvrez Réglages → Importer / Exporter.
  2. Touchez Importer et choisissez le zip créé par l'export de Kadu.
  3. Attendez le message « Import réussi ».
L'import n'efface rien

Les entrées de la sauvegarde sont ajoutées à celles déjà présentes. Celles qui existent déjà dans Kadu ne sont pas dupliquées : vous pouvez donc importer le même fichier une nouvelle fois sans risque.

Passer à un nouveau téléphone

  1. Sur l'ancien téléphone, faites un export et enregistrez le fichier là où le nouveau pourra y accéder : iCloud Drive, Google Drive ou Fichiers.
  2. Installez Kadu sur le nouveau téléphone.
  3. Importez ce fichier.

Le PIN ne fait pas partie de la sauvegarde. Définissez-le à nouveau sur le nouveau téléphone.

Import depuis Day One

  1. Dans Day One, exportez votre journal au format JSON. Vous obtenez une archive zip.
  2. Dans Kadu, ouvrez Réglages → Importer / Exporter et touchez Importer depuis Day One (zip).
  3. Choisissez l'archive.

Comment les données sont reprises :

  • le journal principal de Day One (« Journal ») va dans la catégorie par défaut ;
  • chaque autre journal reçoit une catégorie du même nom. Si elle existe déjà, les entrées y sont ajoutées ;
  • les photos et les hashtags suivent les entrées.

Import depuis Apple Journal

  1. Exportez vos entrées depuis l'app Journal. Vous obtenez un dossier contenant un fichier index.html et les dossiers Entries et Resources.
  2. Compressez ce dossier en zip. Dans l'app Fichiers, maintenez le dossier appuyé et choisissez Compresser.
  3. Dans Kadu, touchez Importer depuis Apple Journal (zip) et choisissez l'archive.

Si la date d'une entrée n'est pas reconnue, elle reçoit la date du jour. Kadu vous indique combien d'entrées sont concernées. Vous pouvez corriger la date à la main dans l'éditeur.

Questions fréquentes

L'import indique que le fichier ressemble à un export d'une autre app

Vous avez choisi une archive Day One ou Apple Journal dans l'option normale Importer. Ces archives ont leurs propres boutons : Importer depuis Day One (zip) et Importer depuis Apple Journal (zip). Kadu vous indiquera lequel utiliser.

« Aucun fichier data.json trouvé dans l'archive. »

Le fichier n'est pas une sauvegarde Kadu ou a été modifié après l'export. Choisissez bien le zip d'origine créé avec Exporter toutes les données.

L'export est très long

Kadu copie toutes les photos et vidéos dans l'archive, et pour un grand journal cela prend quelques minutes. Gardez l'app ouverte jusqu'à la fin.
