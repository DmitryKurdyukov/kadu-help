Catégories privées et PIN

Kadu offre deux niveaux de protection. Une catégorie privée cache les entrées de la frise générale, et un code PIN verrouille l'app elle-même et les catégories privées.

Catégorie privée

Les entrées d'une catégorie privée n'apparaissent jamais dans la frise générale, les filtres ni les diaporamas généraux. Le seul moyen de les voir est d'ouvrir la catégorie elle-même depuis l'écran d'accueil.

Rendre une catégorie privée

  1. Sur l'écran d'accueil, maintenez appuyée la carte d'une catégorie. Pour une nouvelle catégorie, touchez Ajouter une catégorie.
  2. Activez l'interrupteur Privée (légende : « Cachée dans la frise générale »).
  3. Touchez Enregistrer (pour une nouvelle catégorie : Créer).

Au premier lancement, Kadu crée déjà une catégorie « Privé ».

Sans PIN, la confidentialité n'est que visuelle

Tant qu'aucun PIN n'est défini, une catégorie privée est seulement masquée de la frise. Quiconque tient votre téléphone peut l'ouvrir depuis l'écran d'accueil. Pour vraiment la verrouiller, définissez un PIN.

Code PIN

Le définir

  1. Ouvrez Réglages → Code PIN.
  2. Touchez Définir le code PIN.
  3. Saisissez 4 chiffres et répétez-les pour confirmer.

Quand Kadu demande le PIN

  • à chaque ouverture de l'app ;
  • à l'ouverture d'une catégorie privée depuis l'écran d'accueil ;
  • avant l'export des données, car la sauvegarde contient aussi les entrées privées.

Le changer ou le désactiver

Ouvrez Réglages → Code PIN → Réinitialiser le code PIN et saisissez le code actuel. L'app cesse alors de le demander. Pour en définir un nouveau, touchez de nouveau Définir le code PIN.

Faux PIN

Si quelqu'un risque de vous demander de déverrouiller votre journal, définissez un second code, factice. Il ouvre l'app mais masque toutes les catégories privées. Plus d'infos dans Faux PIN.

Questions fréquentes

J'ai oublié mon PIN

Le PIN est stocké uniquement sur votre appareil, sous forme chiffrée : il ne peut être ni récupéré ni consulté, pas même par nous. Essayez de vous en souvenir. Sinon, écrivez-nous.

Pour éviter cela, choisissez un code que vous n'oublierez pas et faites des sauvegardes régulièrement.

Puis-je ouvrir Kadu avec Face ID ?

Pas encore : Kadu est protégé uniquement par un PIN.
