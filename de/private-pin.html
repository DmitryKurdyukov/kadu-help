Private Kategorien & PIN

Kadu hat zwei Schutzstufen. Eine private Kategorie verbirgt Einträge aus der allgemeinen Zeitleiste, und eine PIN sperrt die App selbst und die privaten Kategorien.

Private Kategorie

Einträge aus einer privaten Kategorie erscheinen nie in der allgemeinen Zeitleiste, in Filtern oder allgemeinen Diashows. Sehen kannst du sie nur, indem du die Kategorie selbst vom Startbildschirm aus öffnest.

So machst du eine Kategorie privat

  1. Halte auf dem Startbildschirm eine Kategoriekarte gedrückt. Für eine neue Kategorie tippe auf Kategorie hinzufügen.
  2. Schalte Privat ein (Untertitel: „In der allgemeinen Zeitleiste verborgen“).
  3. Tippe auf Speichern (bei einer neuen Kategorie auf Erstellen).

Beim ersten Start legt Kadu bereits die Kategorie „Privat“ an.

Ohne PIN ist die Privatsphäre nur optisch

Solange keine PIN gesetzt ist, ist eine private Kategorie nur aus der Zeitleiste ausgeblendet. Wer dein Handy in der Hand hat, kann sie vom Startbildschirm aus öffnen. Um sie wirklich zu sperren, setze eine PIN.

PIN

So setzt du sie

  1. Öffne Einstellungen → PIN-Code.
  2. Tippe auf PIN-Code festlegen.
  3. Gib 4 Ziffern ein und wiederhole sie zur Bestätigung.

Wann Kadu nach der PIN fragt

  • bei jedem App-Start;
  • beim Öffnen einer privaten Kategorie vom Startbildschirm;
  • vor dem Datenexport, da das Backup auch private Einträge enthält.

So änderst oder deaktivierst du sie

Öffne Einstellungen → PIN-Code → PIN-Code zurücksetzen und gib den aktuellen Code ein. Danach fragt die App nicht mehr danach. Für einen neuen Code tippe erneut auf PIN-Code festlegen.

Falsche PIN

Falls dich jemand bitten könnte, dein Tagebuch zu entsperren, lege einen zweiten, falschen Code fest. Er öffnet die App, verbirgt aber alle privaten Kategorien. Mehr unter Falsche PIN.

Häufige Fragen

Ich habe meine PIN vergessen

Die PIN wird nur auf deinem Gerät und verschlüsselt gespeichert, daher kann sie niemand wiederherstellen oder auslesen – auch wir nicht. Versuche, dich zu erinnern. Wenn das nicht klappt, schreib uns.

Um das zu vermeiden, wähle einen Code, den du nicht vergisst, und erstelle regelmäßig Backups.

Kann ich Kadu mit Face ID öffnen?

Noch nicht – Kadu wird nur per PIN geschützt.
