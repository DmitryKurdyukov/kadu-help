Falsche PIN Premium

Eine falsche PIN ist ein zweiter Code für Kadu. Sie öffnet die App wie gewohnt, nur ohne private Kategorien. Für Zuschauer sieht es aus, als hätte es sie nie gegeben.

Wozu sie dient

Manchmal wirst du gebeten, dein Tagebuch zu zeigen, und es ist unangenehm abzulehnen. Gib den falschen Code ein: Die andere Person sieht normale Einträge, Persönliches bleibt verborgen. Auf dem Bildschirm gibt es keinen „Modus“ und keinen Hinweis.

Was nach Eingabe des falschen Codes passiert

  • private Kategorien verschwinden vom Startbildschirm;
  • ihre Einträge erscheinen nicht in Zeitleiste, Filtern, Diashow, Buch oder Export;
  • alles andere funktioniert wie gewohnt.

Es werden keine Daten gelöscht. Gibst du deine echte PIN ein, ist alles wieder da.

So setzt du sie

  1. Setze zuerst deine Haupt-PIN: Einstellungen → PIN-Code → PIN-Code festlegen. Ohne sie fragt die App beim Start nach keinem Code, eine falsche PIN wäre also nutzlos.
  2. Tippe auf Fake-PIN festlegen.
  3. Gib 4 Ziffern ein und wiederhole sie.
Die Codes müssen sich unterscheiden

Stimmt der falsche Code mit dem Hauptcode überein, öffnet Kadu immer im normalen Modus, und der falsche Code funktioniert nicht.

So deaktivierst du sie

Öffne Einstellungen → PIN-Code → Fake-PIN zurücksetzen und gib deine Haupt-PIN ein. Der falsche Code kann sich nicht selbst zurücksetzen – sonst könnte jeder, der ihn kennt, den Schutz abschalten.

Häufige Fragen

Wie komme ich nach dem falschen Code zurück zum vollständigen Tagebuch?

Schließe die App vollständig, öffne sie erneut und gib deine Haupt-PIN ein.
