Export & Import

Der Export erstellt ein Backup deines Tagebuchs als eine einzige ZIP-Datei. Der Import stellt es wieder her oder übernimmt Einträge aus Day One und Apple Journal. Alles findest du unter Einstellungen → Importieren / Exportieren.

Export: Backup

  1. Öffne Einstellungen → Importieren / Exportieren → Exportieren.
  2. Tippe auf Alle Daten exportieren. Ist eine PIN gesetzt, fragt Kadu zuerst danach.
  3. Warte, bis es fertig ist. Bei vielen Fotos und Videos kann das einige Minuten dauern.
  4. Wähle im geöffneten Fenster, wo die Datei gespeichert wird: In „Dateien“ sichern (z. B. iCloud Drive), an einen Computer oder in einen Cloudspeicher senden.

Die Datei heißt etwa kadu-export-10-19-2026.zip. Sie enthält alle Einträge, Kategorien, Tags, Fotos, Videos und Sprachnotizen.

Eine Kategorie exportieren Premium

Auf demselben Bildschirm kannst du im Block Nach Kategorie exportieren nur die Einträge einer Kategorie exportieren – etwa um ein Reisetagebuch zu teilen.

Ein Kadu-Backup importieren

  1. Öffne Einstellungen → Importieren / Exportieren.
  2. Tippe auf Importieren und wähle die von Kadu exportierte ZIP-Datei.
  3. Warte auf die Meldung „Import erfolgreich“.
Der Import löscht nichts

Einträge aus dem Backup werden zu den vorhandenen hinzugefügt. Einträge, die schon in Kadu sind, werden nicht doppelt angelegt – du kannst dieselbe Datei also gefahrlos erneut importieren.

Umzug auf ein neues Handy

  1. Mach auf dem alten Handy einen Export und speichere die Datei dort, wo das neue Handy herankommt: iCloud Drive, Google Drive oder Dateien.
  2. Installiere Kadu auf dem neuen Handy.
  3. Importiere diese Datei.

Die PIN ist nicht Teil des Backups. Lege sie auf dem neuen Handy neu fest.

Import aus Day One

  1. Exportiere dein Journal in Day One im Format JSON. Du erhältst ein ZIP-Archiv.
  2. Öffne in Kadu Einstellungen → Importieren / Exportieren und tippe auf Von Day One importieren (zip).
  3. Wähle das Archiv.

So werden die Daten übernommen:

  • das Haupt-Journal von Day One („Journal“) kommt in die Standardkategorie;
  • jedes weitere Journal erhält eine Kategorie mit gleichem Namen. Gibt es sie schon, kommen die Einträge dort hinein;
  • Fotos und Hashtags werden mit den Einträgen übernommen.

Import aus Apple Journal

  1. Exportiere deine Einträge aus der App Journal. Du erhältst einen Ordner mit einer Datei index.html und den Ordnern Entries und Resources.
  2. Komprimiere diesen Ordner als ZIP. Halte ihn in der App Dateien gedrückt und wähle Komprimieren.
  3. Tippe in Kadu auf Von Apple Journal importieren (zip) und wähle das Archiv.

Kann das Datum eines Eintrags nicht erkannt werden, erhält er das heutige Datum. Kadu sagt dir, wie viele es sind. Du kannst das Datum im Editor von Hand korrigieren.

Häufige Fragen

Der Import meldet, die Datei sehe wie ein Export aus einer anderen App aus

Du hast ein Day-One- oder Apple-Journal-Archiv im normalen Punkt Importieren gewählt. Für solche Archive gibt es eigene Tasten: Von Day One importieren (zip) und Von Apple Journal importieren (zip). Kadu sagt dir, welche du nehmen musst.

„Keine data.json im Archiv gefunden.“

Die Datei ist kein Kadu-Backup oder wurde nach dem Export verändert. Wähle die originale ZIP-Datei, die mit Alle Daten exportieren erstellt wurde.

Der Export dauert sehr lange

Kadu kopiert alle Fotos und Videos ins Archiv, und bei einem großen Tagebuch dauert das einige Minuten. Lass die App bis zum Ende geöffnet.
