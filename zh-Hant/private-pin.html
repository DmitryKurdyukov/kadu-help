私人分類與 PIN 碼

Kadu 有兩層保護。私人分類會把記錄從總時間線中隱藏，PIN 碼則鎖定 App 本身和私人分類。

私人分類

私人分類中的記錄永遠不會出現在總時間線、篩選或總投影片中。檢視它們的唯一方式，是從主頁開啟這個分類本身。

如何把分類設為私人

  1. 在主頁長按分類卡片。如果是新分類，點按 新增分類。
  2. 開啟 私密 開關（說明文字：「在公共時間線中隱藏」）。
  3. 點按 儲存（新分類為 建立）。

首次啟動時，Kadu 已經建立好「私密」分類。

沒有 PIN 碼時，隱私只是視覺上的

在設定 PIN 碼之前，私人分類只是從時間線中隱藏。任何拿著你手機的人都能從主頁開啟它。要真正鎖住它，請設定 PIN 碼。

PIN 碼

如何設定

  1. 開啟 設定 → PIN 碼。
  2. 點按 設定 PIN 碼。
  3. 輸入 4 位數字，再輸入一次確認。

Kadu 何時要求輸入 PIN 碼

  • 每次啟動 App 時；
  • 從主頁開啟私人分類時；
  • 匯出資料之前，因為備份中也包含私人記錄。

如何更改或關閉

開啟 設定 → PIN 碼 → 重置 PIN 碼 並輸入當前密碼。之後 App 不再要求輸入。要設定新密碼，請再次點按 設定 PIN 碼。

偽裝 PIN 碼

如果有人可能讓你解鎖日記，可以設定第二個偽裝密碼。它能開啟 App，但會隱藏所有私人分類。詳見偽裝 PIN 碼。

常見問題

我忘了 PIN 碼

PIN 碼只以加密形式儲存在你的裝置上，因此任何人都無法恢復或檢視——包括我們。請儘量回想。如果實在想不起來，請給我們留言。

為避免這種情況，請選擇一個不會忘記的密碼，並定期備份。

可以用Face ID 開啟 Kadu 嗎？

暫時不行——Kadu 只用 PIN 碼保護。
