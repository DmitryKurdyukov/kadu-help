匯出與匯入

匯出會把日記備份成一個 zip 檔案。匯入可以恢復備份，或從 Day One 和 Apple Journal 遷入記錄。這些都在 設定 → 匯入 / 匯出 中。

匯出：備份

  1. 開啟 設定 → 匯入 / 匯出 → 匯出。
  2. 點按 匯出所有資料。如果設定了 PIN 碼，Kadu 會先要求輸入。
  3. 等待完成。照片和影片很多時，可能需要幾分鐘。
  4. 在彈出的視窗中選擇儲存位置：儲存到「檔案」（例如 iCloud 雲碟）、傳送到電腦或雲端儲存。

檔名類似 kadu-export-10-19-2026.zip。其中包含所有記錄、分類、標籤、照片、影片和語音備忘。

匯出單個分類 Premium

在同一頁面的 按分類匯出 區域，可以只匯出一個分類的記錄——比如分享一本旅行日記。

匯入 Kadu 備份

  1. 開啟 設定 → 匯入 / 匯出。
  2. 點按 匯入，選擇 Kadu 匯出的 zip 檔案。
  3. 等待出現「匯入成功」提示。
匯入不會刪除任何內容

備份中的記錄會新增到 App 中已有的記錄裡。Kadu 中已存在的記錄不會重複，所以同一個檔案再匯入一次也沒關係。

換新手機

  1. 在舊手機上匯出，把檔案儲存到新手機能訪問的地方：iCloud 雲碟、Google Drive 或「檔案」。
  2. 在新手機上安裝 Kadu。
  3. 匯入這個檔案。

PIN 碼不包含在備份中。請在新手機上重新設定。

從 Day One 匯入

  1. 在 Day One 中以 JSON 格式匯出日記。你會得到一個 zip 壓縮包。
  2. 在 Kadu 中開啟 設定 → 匯入 / 匯出，點按 從 Day One 匯入（zip）。
  3. 選擇該壓縮包。

資料遷移方式：

  • Day One 的主日記（「Journal」）進入預設分類；
  • 其他每本日記都會得到一個同名分類。如果已存在，記錄會加入該分類；
  • 照片和話題標籤會隨記錄一起遷移。

從 Apple Journal 匯入

  1. 從「日記」App 匯出記錄。你會得到一個資料夾，其中有 index.html 檔案以及 Entries 和 Resources 資料夾。
  2. 把該資料夾壓縮為 zip。在「檔案」App 中長按資料夾，選擇 壓縮。
  3. 在 Kadu 中點按 從 Apple Journal 匯入（zip） 並選擇該壓縮包。

無法識別日期的記錄會被設為今天的日期。Kadu 會告訴你有多少條。你可以在編輯器中手動修改日期。

常見問題

匯入提示檔案看起來像其他 App 的匯出檔案

你在普通的 匯入 中選擇了 Day One 或 Apple Journal 的壓縮包。這類壓縮包有專門的按鈕：從 Day One 匯入（zip） 和 從 Apple Journal 匯入（zip）。Kadu 會告訴你該用哪一個。

「壓縮包中未找到 data.json。」

該檔案不是 Kadu 備份，或者匯出後被修改過。請選擇用 匯出所有資料 生成的原始 zip 檔案。

匯出需要很長時間

Kadu 會把所有照片和影片複製進壓縮包，日記較大時需要幾分鐘。請保持 App 開啟直到完成。
