標籤

標籤用一個共同主題把記錄串起來：一次旅行、一個人、一個專案。Kadu 沒有單獨的標籤輸入框——標籤直接寫在記錄正文裡。

如何新增標籤

  1. 在正文中輸入 #，緊接著輸入一個詞，中間不要空格：#旅行。
  2. 在詞後面輸入一個空格。只有這樣它才會變成真正的標籤。
  3. 確認標籤 #旅行 以強調色高亮顯示。
  4. 儲存記錄。
終於到海邊了 #旅行 #海邊2025 喝杯咖啡
最重要的規則：標籤必須高亮

如果帶 # 的詞仍是普通文字、沒有變色，它就不是標籤。它不會出現在篩選裡，也無法透過它找到記錄。最常見的原因是標籤後面少了空格——比如它是正文的最後一個詞。

一條記錄可以有任意多個標籤，放在正文的開頭、中間或結尾都可以。只要每個標籤後面都有空格。

標籤沒有高亮怎麼辦

把游標放在詞的後面，按一下空格。如果還不行，刪掉標籤重新輸入：#、詞、空格。

書寫規則

示例結果原因
#Travel 和 #travel同一個標籤 travel不區分大小寫
#初雪 那天只有 初雪空格會結束標籤
#約會、#ความทรงจำ可以使用任何語言的文字都行
提示

由多個片語成的標籤，可以用下劃線或連字元連線：#生日_派對、#first-snow。

按標籤查詢記錄

  1. 開啟 時間線 標籤頁。
  2. 點按螢幕頂部的 篩選。
  3. 在 標籤 區域勾選需要的標籤。標籤很多時，在 搜尋標籤… 框中輸入名稱。
  4. 應用篩選。

最常用的標籤排在最前面。

選擇了多個標籤時

時間線會顯示包含所選標籤中至少一個的記錄。例如選擇 #海邊 和 #山，海邊和山裡的旅行都會顯示。

要取消全部選擇，點按區域標題旁的 清除。

標籤篩選同樣作用於投影片和書。例如勾選 #旅行，就能看一部只關於這次旅行的影片。詳見篩選與搜尋。

修改或刪除標籤

開啟記錄，修改或刪除帶 # 的詞並儲存。標籤列表會自動更新。當沒有任何記錄再使用某個標籤時，它會從篩選中消失。

常見問題

篩選裡顯示還沒有標籤

標籤只有在至少一條已儲存的記錄中使用過之後才會出現。請確認標籤已高亮——帶 # 的普通文字不算標籤。

Day One 或 Apple Journal 的標籤會保留嗎？

會。匯入時，Kadu 會在匯入記錄的正文中找出話題標籤並加入列表。

記錄明明存在，卻按標籤找不到

檢查三點：

  • 記錄中的標籤是否以強調色高亮。如果沒有，在它後面加一個空格並重新儲存記錄；
  • 篩選會精確查詢 # 後面的詞：中間有空格會結束標籤；
  • 記錄不在私人分類中：總時間線不會顯示它們。
