PIN falso Premium

O PIN falso é um segundo código para o Kadu. Ele abre o app normalmente, só que sem as categorias privadas. Para quem olha, é como se elas nunca tivessem existido.

Para que serve

Às vezes pedem para ver seu diário e é constrangedor recusar. Digite o código falso: a outra pessoa vê registros comuns, e os pessoais continuam escondidos. Não aparece nenhum “modo” nem aviso na tela.

O que acontece depois do código falso

  • as categorias privadas somem da tela inicial;
  • os registros delas não aparecem na linha do tempo, nos filtros, na apresentação, no livro nem na exportação;
  • todo o resto funciona normalmente.

Nenhum dado é apagado. Quando você digita seu PIN verdadeiro, tudo volta ao lugar.

Como definir

  1. Primeiro defina seu PIN principal: Configurações → Código PIN → Definir código PIN. Sem ele, o app não pede código ao abrir, então um PIN falso não serve.
  2. Toque em Definir PIN falso.
  3. Digite 4 números e repita.
Os códigos precisam ser diferentes

Se o código falso for igual ao principal, o Kadu sempre abrirá no modo normal e o código falso não funcionará.

Como desativar

Abra Configurações → Código PIN → Redefinir PIN falso e digite seu PIN principal. O código falso não consegue desativar a si mesmo — senão qualquer pessoa que o conheça poderia desligar a proteção.

Perguntas frequentes

Como volto ao diário completo depois do código falso?

Feche o app por completo, abra de novo e digite seu PIN principal.
