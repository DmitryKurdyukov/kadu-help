Tags

As tags ligam registros por um tema comum: uma viagem, uma pessoa, um projeto. O Kadu não tem um campo separado para elas — as tags são escritas direto no texto do registro.

Como adicionar uma tag

  1. Digite # no texto seguido de uma palavra, sem espaço: #ferias.
  2. Digite um espaço depois da palavra. Só então ela vira uma tag de verdade.
  3. Confira se a tag #ferias ficou destacada na cor de destaque.
  4. Salve o registro.
Finalmente chegamos à praia #ferias #praia2025 e tomando um café
A regra principal: a tag precisa ficar destacada

Se uma palavra com # continua como texto comum em vez de ganhar cor, ela não é uma tag. Não aparecerá nos filtros e o registro não será encontrado por ela. Isso costuma acontecer quando falta o espaço depois da tag — por exemplo, se ela for a última palavra do texto.

Um registro pode ter quantas tags você quiser, em qualquer lugar do texto: no início, no meio ou no fim. Só coloque um espaço depois de cada uma.

A tag não ficou destacada — o que fazer

Coloque o cursor logo depois da palavra e aperte espaço. Se não resolver, apague a tag e digite de novo: #, a palavra, um espaço.

Dica

Para tags com várias palavras, junte-as com sublinhado ou hífen: #primeira_neve, #festa-aniversario.

Como encontrar registros por tag

  1. Abra a aba Linha do tempo.
  2. Toque em Filtros no topo da tela.
  3. No bloco Tags, marque as tags desejadas. Se forem muitas, comece a digitar no campo Buscar tags….
  4. Aplique o filtro.

As tags mais usadas aparecem primeiro.

Se várias tags estiverem marcadas

A linha do tempo mostra os registros com pelo menos uma das tags marcadas. Por exemplo, com #praia e #montanha você verá viagens à praia e à montanha.

Para desmarcar todas, toque em Limpar ao lado do título do bloco.

O filtro por tag também vale para a apresentação e o livro. Por exemplo, marque #ferias e assista a um filme só dessas férias. Mais em Filtros e busca.

Como mudar ou remover uma tag

Abra o registro, edite ou apague a palavra com # e salve. A lista de tags se atualiza sozinha. Uma tag some dos filtros quando nenhum registro a usa mais.

Perguntas frequentes

Os filtros dizem que ainda não há tags

As tags só aparecem depois de usadas em pelo menos um registro salvo. Confira se a tag está destacada em cor — texto comum com # não conta como tag.

As tags do Day One ou do Apple Journal são mantidas?

Sim. Na importação, o Kadu encontra as hashtags no texto dos registros importados e as adiciona à lista.

Não encontro uma tag, mas o registro existe

Confira três coisas:

  • a tag está destacada na cor de destaque no registro. Se não, adicione um espaço depois dela e salve o registro de novo;
  • os filtros buscam exatamente a palavra depois do #: um espaço no meio encerra a tag;
  • o registro não está numa categoria privada: a linha do tempo geral não as mostra.
