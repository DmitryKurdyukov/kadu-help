Categorias privadas e PIN

O Kadu tem dois níveis de proteção. Uma categoria privada esconde registros da linha do tempo geral, e um PIN bloqueia o próprio app e as categorias privadas.

Categoria privada

Os registros de uma categoria privada nunca aparecem na linha do tempo geral, nos filtros nem nas apresentações gerais. A única forma de vê-los é abrir a própria categoria pela tela inicial.

Como tornar uma categoria privada

  1. Na tela inicial, toque e segure o cartão de uma categoria. Para uma categoria nova, toque em Adicionar categoria.
  2. Ative a chave Privada (legenda: “Oculta na linha do tempo geral”).
  3. Toque em Salvar (para uma categoria nova, Criar).

Na primeira abertura, o Kadu já cria a categoria “Privado”.

Sem PIN, a privacidade é só visual

Enquanto não houver PIN, uma categoria privada só fica oculta da linha do tempo. Qualquer pessoa com seu celular na mão consegue abri-la pela tela inicial. Para bloqueá-la de verdade, defina um PIN.

PIN

Como definir

  1. Abra Configurações → Código PIN.
  2. Toque em Definir código PIN.
  3. Digite 4 números e repita para confirmar.

Quando o Kadu pede o PIN

  • toda vez que o app é aberto;
  • ao abrir uma categoria privada pela tela inicial;
  • antes da exportação de dados, porque o backup também contém registros privados.

Como mudar ou desativar

Abra Configurações → Código PIN → Redefinir código PIN e digite o código atual. Depois disso, o app para de pedi-lo. Para definir um novo, toque de novo em Definir código PIN.

PIN falso

Se alguém puder pedir que você desbloqueie seu diário, defina um segundo código, falso. Ele abre o app, mas esconde todas as categorias privadas. Mais em PIN falso.

Perguntas frequentes

Esqueci meu PIN

O PIN fica guardado só no seu aparelho e criptografado, então não pode ser recuperado nem consultado — nem por nós. Tente lembrar. Se não conseguir, escreva para nós.

Para evitar isso, escolha um código que você não vá esquecer e faça backups com frequência.

Dá para abrir o Kadu com Face ID?

Ainda não — o Kadu é protegido só por PIN.
