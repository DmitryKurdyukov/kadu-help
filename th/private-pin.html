หมวดหมู่ส่วนตัวและ PIN

Kadu มีการป้องกันสองระดับ หมวดหมู่ส่วนตัวซ่อนบันทึกจากไทม์ไลน์รวม และ PIN ล็อกตัวแอปรวมถึงหมวดหมู่ส่วนตัว

หมวดหมู่ส่วนตัว

บันทึกในหมวดหมู่ส่วนตัวจะไม่ปรากฏในไทม์ไลน์รวมเลย รวมถึงในตัวกรองและสไลด์โชว์รวม วิธีเดียวที่จะเห็นคือเปิดหมวดหมู่นั้นจากหน้าแรก

วิธีตั้งหมวดหมู่เป็นส่วนตัว

  1. ที่หน้าแรก กดค้างที่การ์ดหมวดหมู่ สำหรับหมวดหมู่ใหม่ ให้แตะ เพิ่มหมวดหมู่
  2. เปิดสวิตช์ ส่วนตัว (มีคำอธิบายว่า "ซ่อนจากไทม์ไลน์ทั่วไป")
  3. แตะ บันทึก (สำหรับหมวดหมู่ใหม่คือ สร้าง)

เมื่อเปิดครั้งแรก Kadu สร้างหมวดหมู่ "ส่วนตัว" ไว้ให้แล้ว

หากไม่มี PIN ความเป็นส่วนตัวมีแค่ภายนอก

ตราบใดที่ยังไม่ได้ตั้ง PIN หมวดหมู่ส่วนตัวแค่ถูกซ่อนจากไทม์ไลน์ ใครก็ตามที่ถือโทรศัพท์ของคุณเปิดได้จากหน้าแรก หากต้องการล็อกจริง ให้ตั้ง PIN

PIN

วิธีตั้ง

  1. เปิด การตั้งค่า → รหัส PIN
  2. แตะ ตั้งรหัส PIN
  3. ใส่ตัวเลข 4 หลัก แล้วใส่อีกครั้งเพื่อยืนยัน

Kadu ขอ PIN เมื่อไร

  • ทุกครั้งที่เปิดแอป
  • เมื่อเปิดหมวดหมู่ส่วนตัวจากหน้าแรก
  • ก่อนส่งออกข้อมูล เพราะข้อมูลสำรองมีบันทึกส่วนตัวด้วย

วิธีเปลี่ยนหรือปิด

เปิด การตั้งค่า → รหัส PIN → รีเซ็ตรหัส PIN แล้วใส่รหัสปัจจุบัน หลังจากนั้นแอปจะไม่ขอรหัสอีก หากต้องการตั้งรหัสใหม่ ให้แตะ ตั้งรหัส PIN อีกครั้ง

PIN ปลอม

หากมีคนอาจขอให้คุณปลดล็อกไดอารี่ ให้ตั้งรหัสที่สองซึ่งเป็นรหัสปลอม รหัสนี้เปิดแอปได้แต่ซ่อนหมวดหมู่ส่วนตัวทั้งหมด ดูเพิ่มเติมที่PIN ปลอม

คำถามที่พบบ่อย

ฉันลืม PIN

PIN ถูกเก็บไว้บนอุปกรณ์ของคุณเท่านั้นและเข้ารหัสไว้ จึงไม่มีใครกู้คืนหรือดูได้ รวมถึงเราด้วย ลองนึกดูอีกครั้ง หากยังนึกไม่ออก เขียนถึงเรา

เพื่อป้องกันปัญหานี้ ให้เลือกรหัสที่คุณจะไม่ลืม และสำรองข้อมูลสม่ำเสมอ

เปิด Kadu ด้วย Face ID ได้ไหม?

ยังไม่ได้ ตอนนี้ Kadu ป้องกันด้วย PIN เท่านั้น
