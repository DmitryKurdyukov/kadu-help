Ekspor dan impor

Ekspor membuat cadangan jurnal Anda dalam satu file zip. Impor memulihkannya atau memindahkan catatan dari Day One dan Apple Journal. Semuanya ada di Pengaturan → Impor / Ekspor.

Ekspor: cadangan

  1. Buka Pengaturan → Impor / Ekspor → Ekspor.
  2. Ketuk Ekspor semua data. Jika PIN diatur, Kadu memintanya lebih dulu.
  3. Tunggu sampai selesai. Dengan banyak foto dan video, ini bisa memakan beberapa menit.
  4. Di jendela yang terbuka, pilih tempat menyimpan file: Simpan ke File (misalnya iCloud Drive), kirim ke komputer, atau ke penyimpanan cloud.

Nama filenya kira-kira kadu-export-10-19-2026.zip. Isinya semua catatan, kategori, tag, foto, video, dan catatan suara.

Ekspor satu kategori Premium

Di layar yang sama, blok Ekspor per kategori memungkinkan Anda mengekspor catatan dari satu kategori saja — misalnya untuk berbagi jurnal perjalanan.

Impor cadangan Kadu

  1. Buka Pengaturan → Impor / Ekspor.
  2. Ketuk Impor lalu pilih file zip hasil ekspor Kadu.
  3. Tunggu pesan "Impor berhasil".
Impor tidak menghapus apa pun

Catatan dari cadangan ditambahkan ke catatan yang sudah ada di aplikasi. Catatan yang sudah ada di Kadu tidak ditambahkan dua kali, jadi Anda bisa mengimpor file yang sama lagi dengan aman.

Pindah ke ponsel baru

  1. Di ponsel lama, lakukan ekspor dan simpan file di tempat yang bisa dijangkau ponsel baru: iCloud Drive, Google Drive, atau File.
  2. Pasang Kadu di ponsel baru.
  3. Impor file tersebut.

PIN tidak termasuk dalam cadangan. Atur lagi di ponsel baru.

Impor dari Day One

  1. Di Day One, ekspor jurnal Anda dalam format JSON. Anda akan mendapat arsip zip.
  2. Di Kadu, buka Pengaturan → Impor / Ekspor lalu ketuk Impor dari Day One (zip).
  3. Pilih arsipnya.

Cara data dipindahkan:

  • jurnal utama Day One ("Journal") masuk ke kategori bawaan;
  • setiap jurnal lain mendapat kategori dengan nama yang sama. Jika sudah ada, catatan ditambahkan ke sana;
  • foto dan hashtag ikut pindah bersama catatan.

Impor dari Apple Journal

  1. Ekspor catatan Anda dari app Jurnal. Anda akan mendapat folder berisi file index.html serta folder Entries dan Resources.
  2. Kompres folder itu menjadi zip. Di app File, tekan lama folder lalu pilih Kompres.
  3. Di Kadu, ketuk Impor dari Apple Journal (zip) lalu pilih arsipnya.

Jika tanggal sebuah catatan tidak dikenali, catatan itu diberi tanggal hari ini. Kadu memberi tahu berapa banyak catatan seperti itu. Anda bisa memperbaiki tanggal secara manual di editor.

Pertanyaan umum

Impor bilang file tampak seperti ekspor dari aplikasi lain

Anda memilih arsip Day One atau Apple Journal di item Impor biasa. Arsip seperti itu punya tombol sendiri: Impor dari Day One (zip) dan Impor dari Apple Journal (zip). Kadu akan memberi tahu mana yang harus dipakai.

"data.json tidak ditemukan di arsip."

File itu bukan cadangan Kadu atau telah diubah setelah ekspor. Pilih file zip asli yang dibuat dengan Ekspor semua data.

Ekspor memakan waktu sangat lama

Kadu menyalin semua foto dan video ke dalam arsip, dan untuk jurnal besar ini butuh beberapa menit. Biarkan aplikasi tetap terbuka sampai selesai.
