导出与导入

导出会把日记备份成一个 zip 文件。导入可以恢复备份，或从 Day One 和 Apple Journal 迁入记录。这些都在 设置 → 导入 / 导出 中。

导出：备份

  1. 打开 设置 → 导入 / 导出 → 导出。
  2. 点按 导出所有数据。如果设置了 PIN 码，Kadu 会先要求输入。
  3. 等待完成。照片和视频很多时，可能需要几分钟。
  4. 在弹出的窗口中选择保存位置：存储到“文件”（例如 iCloud 云盘）、发送到电脑或云存储。

文件名类似 kadu-export-10-19-2026.zip。其中包含所有记录、分类、标签、照片、视频和语音备忘。

导出单个分类 Premium

在同一页面的 按分类导出 区域，可以只导出一个分类的记录——比如分享一本旅行日记。

导入 Kadu 备份

  1. 打开 设置 → 导入 / 导出。
  2. 点按 导入，选择 Kadu 导出的 zip 文件。
  3. 等待出现“导入成功”提示。
导入不会删除任何内容

备份中的记录会添加到 App 中已有的记录里。Kadu 中已存在的记录不会重复，所以同一个文件再导入一次也没关系。

换新手机

  1. 在旧手机上导出，把文件保存到新手机能访问的地方：iCloud 云盘、Google Drive 或“文件”。
  2. 在新手机上安装 Kadu。
  3. 导入这个文件。

PIN 码不包含在备份中。请在新手机上重新设置。

从 Day One 导入

  1. 在 Day One 中以 JSON 格式导出日记。你会得到一个 zip 压缩包。
  2. 在 Kadu 中打开 设置 → 导入 / 导出，点按 从 Day One 导入（zip）。
  3. 选择该压缩包。

数据迁移方式：

  • Day One 的主日记（“Journal”）进入默认分类；
  • 其他每本日记都会得到一个同名分类。如果已存在，记录会加入该分类；
  • 照片和话题标签会随记录一起迁移。

从 Apple Journal 导入

  1. 从“手记”App 导出记录。你会得到一个文件夹，其中有 index.html 文件以及 Entries 和 Resources 文件夹。
  2. 把该文件夹压缩为 zip。在“文件”App 中长按文件夹，选择 压缩。
  3. 在 Kadu 中点按 从 Apple Journal 导入（zip） 并选择该压缩包。

无法识别日期的记录会被设为今天的日期。Kadu 会告诉你有多少条。你可以在编辑器中手动修改日期。

常见问题

导入提示文件看起来像其他 App 的导出文件

你在普通的 导入 中选择了 Day One 或 Apple Journal 的压缩包。这类压缩包有专门的按钮：从 Day One 导入（zip） 和 从 Apple Journal 导入（zip）。Kadu 会告诉你该用哪一个。

“压缩包中未找到 data.json。”

该文件不是 Kadu 备份，或者导出后被修改过。请选择用 导出所有数据 生成的原始 zip 文件。

导出需要很长时间

Kadu 会把所有照片和视频复制进压缩包，日记较大时需要几分钟。请保持 App 打开直到完成。
