私人分类与 PIN 码

Kadu 有两层保护。私人分类会把记录从总时间线中隐藏，PIN 码则锁定 App 本身和私人分类。

私人分类

私人分类中的记录永远不会出现在总时间线、筛选或总幻灯片中。查看它们的唯一方式，是从主页打开这个分类本身。

如何把分类设为私人

  1. 在主页长按分类卡片。如果是新分类，点按 添加分类。
  2. 打开 私密 开关（说明文字：“在公共时间线中隐藏”）。
  3. 点按 保存（新分类为 创建）。

首次启动时，Kadu 已经创建好“私密”分类。

没有 PIN 码时，隐私只是视觉上的

在设置 PIN 码之前，私人分类只是从时间线中隐藏。任何拿着你手机的人都能从主页打开它。要真正锁住它，请设置 PIN 码。

PIN 码

如何设置

  1. 打开 设置 → PIN 码。
  2. 点按 设置 PIN 码。
  3. 输入 4 位数字，再输入一次确认。

Kadu 何时要求输入 PIN 码

  • 每次启动 App 时；
  • 从主页打开私人分类时；
  • 导出数据之前，因为备份中也包含私人记录。

如何更改或关闭

打开 设置 → PIN 码 → 重置 PIN 码 并输入当前密码。之后 App 不再要求输入。要设置新密码，请再次点按 设置 PIN 码。

伪装 PIN 码

如果有人可能让你解锁日记，可以设置第二个伪装密码。它能打开 App，但会隐藏所有私人分类。详见伪装 PIN 码。

常见问题

我忘了 PIN 码

PIN 码只以加密形式保存在你的设备上，因此任何人都无法恢复或查看——包括我们。请尽量回想。如果实在想不起来，请给我们留言。

为避免这种情况，请选择一个不会忘记的密码，并定期备份。

可以用面容 ID 打开 Kadu 吗？

暂时不行——Kadu 只用 PIN 码保护。
